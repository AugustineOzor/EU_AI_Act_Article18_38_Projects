# EU_AI_Act_Article18_38_Projects
Developed six interconnected AI governance portfolio projects covering EU AI Act Articles 18–38. The programme addresses documentation retention, operational logging, corrective action, regulatory cooperation, AI supply-chain roles, deployer responsibilities, fundamental-rights assessment, notified-body competence, subcontractor oversight, conformity-assessment continuity, and EU-wide coordination. Each project uses fictional systems and synthetic evidence to demonstrate practical AI governance, risk, compliance and assurance capabilities.

# Portfolio disclaimer
Use a fictional organization and synthetic data. State clearly that the projects demonstrate governance methodology and do not constitute legal advice, certification, accreditation, or a formal conformity assessment.
