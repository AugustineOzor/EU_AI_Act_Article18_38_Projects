# AI Value-Chain Map

```text
Model supplier -> Meridian/provider -> Authorized representative -> Importer -> Distributor -> Deployer -> Affected people
       |                 |                    |                |            |             |
 Cloud, data, testing and integration suppliers support multiple stages under contract.
```

## Governance principle

Each actor receives only the role supported by actual activities. Branding, substantial modification, intended-purpose changes and product integration require reassessment.
