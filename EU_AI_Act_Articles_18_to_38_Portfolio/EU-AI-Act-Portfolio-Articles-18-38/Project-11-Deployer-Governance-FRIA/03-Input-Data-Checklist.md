# Input Data Quality Checklist

- [ ] Data is relevant to the approved purpose.
- [ ] Mandatory fields are accurate and complete.
- [ ] Optional missing data does not automatically disadvantage applicants.
- [ ] Source and transformations are traceable.
- [ ] Representation is assessed for the deployment context.
- [ ] Sensitive attributes and proxy variables are governed.
- [ ] Individuals can correct inaccurate information.
- [ ] New data sources trigger approval and testing.
