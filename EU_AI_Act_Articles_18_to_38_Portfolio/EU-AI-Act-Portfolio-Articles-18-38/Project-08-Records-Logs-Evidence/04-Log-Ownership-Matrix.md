# Log Ownership and Responsibility Matrix

| Log source | Controller | Retention owner | Export available | Portfolio decision |
|---|---|---|---|---|
| Provider application logs | Meridian | Security Operations | Yes | Retain in controlled central platform |
| Deployer human-review logs | Deployer | Deployer | Contract dependent | Require export and evidence clause |
| Cloud infrastructure logs | Cloud provider / Meridian configuration | Meridian service owner | Yes, plan dependent | Confirm plan before production |
| Model API logs | Model supplier | Contract dependent | Limited | Negotiate access, retention and incident support |

The contract must define ownership, control, retention, export format, cost, end-of-contract transfer and regulator access support.
